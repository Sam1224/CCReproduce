## 评分机制（百分制）
- **方法创新性**：30 分
- **实验指标**：15 分
- **实验质量**：15 分
- **方法效率**：10 分
- **方法泛化性**：5 分
- **论文相关性**：25 分

### 评分原则说明
- **相关性不是“是否提到电商”**，而是看它能否真实服务于内容理解、达人画像/风格、审核治理、数据生产、在线巡检或评测链路。
- **创新性** 不只看结构花哨程度，也看是否把一个线上痛点真正改写成更可部署的范式。
- **实验质量** 重点考察是否有清晰 baseline、消融、跨场景验证，以及是否给出可以相信的工程指标。
- **效率** 单独拉出来，原因是内容生态很多链路天然在线、长序列、强成本敏感。
